# Canopy branding

SVG logos for Canopy Box / Canopy AI.

- `canopy-logo.svg` — square mark with soft sage circle (use for Cloudflare Access login logo)
- `canopy-logo-transparent.svg` — same mark without background (dark UI / favicon overlays)
- `canopy-wordmark-light.svg` / `canopy-wordmark-dark.svg` — icon + “Canopy” wordmark
